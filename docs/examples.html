Beispiele

Eine Peripherie, eine Datei.

fse_pb_bsp/examples/ enthält pro Peripherie ein minimales .c. Sie werden unabhängig von der Firmware gebaut und brauchen kein usr/. Am schnellsten geht es in der GUI: Beispiel wählen, Quelltext ansehen, mit einem Klick bauen und flashen.

./ss example_list

Alle verfügbaren Beispiele auflisten.

./ss example_build <name>

Ein Beispiel bauen, z. B. adc → examples/build/adc.elf.

./ss flash_example <name>

Bauen, signieren und via OpenOCD/telnet flashen.

Beide Build-Befehle geben den Pfad zur .c-Quelle aus, so springst du direkt in den Code. Ohne ./ss geht es auch: cd fse_pb_bsp/examples && make adc, make clean räumt auf.
